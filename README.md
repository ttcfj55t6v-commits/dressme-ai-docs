# DressMe AI

Полный репозиторий проекта DressMe AI.

## Файлы

- app.py — Telegram-бот с OpenAI, ЮKassa, тарифами и учетом остатков
- requirements.txt — зависимости Render
- index.html — главная страница сайта
- style.css — стили сайта
- offer.html — публичная оферта
- privacy.html — политика конфиденциальности
- consent.html — согласие на обработку персональных данных
- refund.html — правила возврата
